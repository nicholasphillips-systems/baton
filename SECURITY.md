# Security

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/nicholasphillips-systems/baton/security/advisories/new). Keep credentials, private notes, task registries and application histories out of public issues.

Include the affected command, a minimal reproduction using synthetic data, the impact and version information. The current `main` branch receives fixes.

Baton stores local paths, summaries and handoffs in plain files. Keep the state directory and note folders private to the appropriate local user. The board is advisory and does not provide access control or process isolation.

The optional instruction installer replaces instruction files after backing them up. Review templates before installing. Native applications manage their authentication, permissions and settings.
